# Project Prompt: Code Geass Fan Page

## Overview
A multi-page Code Geass fan site featuring characters, mechas (Knightmares), and factions. The design should embody the show's dark, revolutionary tone with a **black and bloody red** color scheme.

## Pages & Routes

### 1. Landing / Hero Page
- Dramatic banner with series tagline
- **Geass symbol animation** (the Geass sigil/glyph, NOT the eye)
- Sets the dark, revolutionary tone for the entire site
- Navigation to other pages

### 2. Characters Page
- Main cast: Lelouch vi Britannia, Suzaku Kururugi, C.C., Kallen Stadtfeld, etc.
- Character cards with **hover effects** (reveal details, stats, affiliations)
- Visually striking presentation

### 3. Mechas Page (Knightmares)
- Main Knightmares: Lancelot, Gawain, Shinkirō, Guren, etc.
- **Mecha stat comparisons** (speed, power, defense, etc.)
- **Diagrams** showing mecha specs and comparisons

### 4. Factions Page
- Main factions: Holy Britannian Empire, The Black Knights, Geass Order, etc.
- **Faction diagrams** showing hierarchy and structure
- Relationships between factions

## Design Requirements
- **Primary colors:** Black (#000000, near-blacks) and Bloody Red (#8B0000, #CC0000, darker reds)
- Dark, revolutionary aesthetic throughout
- Hover effects on interactive elements
- Responsive design
- Geass symbol animation on landing (the Geass glyph/sigil spinning or pulsing)

## Tech Stack
Left to the Tarot Club to decide. Choose whatever fits best for a visually rich, multi-page static site.
