# Design System

### Key Features

## Theme
- **Mode**: dark

## Colors
- **Primary** (#a51d2d): CTAs, active states, key interactive elements
- **Secondary** (#475569): Supporting UI, chips, secondary actions
- **Surface** (#0b1326): Page backgrounds
- **Text** (#dae2fd): Primary text
- **Error** (#1a5fb4): Validation errors, destructive actions
- **Success** (#e5a50a): Success states, confirmations

## Typography
- **Font Family**: Plus Jakarta Sans
- **Base Size**: 15px
- **Body Weight**: 500
- **Headlines**: Plus Jakarta Sans, semi-bold (600)
- **Body**: Plus Jakarta Sans, medium, 15px
- **Labels**: Plus Jakarta Sans, medium (500), 13px, uppercase for section headers

## Spacing
- **Density**: compact
- **Scale**: 4px / 8px / 12px / 16px / 24px

## Components
- **Border Radius**: 11px (rounded)
- **Buttons**: rounded corners, primary uses brand color fill, secondary uses muted fill
- **Inputs**: 1px border, surface background, 11px radius
- **Cards**: No elevation, 1px border, surface background, 15px radius
- **Badges**: Tinted background matching their semantic color, 11px radius

## Do's and Don'ts
- Do use the primary color sparingly, only for the most important action per view
- Don't mix corner styles — keep rounded consistently
- Do maintain 4.5:1 contrast ratio for all text (WCAG AA)
- Don't use more than 3 font weights on a single page
- Do use the spacing scale consistently — no arbitrary pixel values
